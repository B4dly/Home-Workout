# HomeBulk — Personalized Home Workout & Bulking Planner

HomeBulk is a mobile-first, single-file web app for building muscle and strength at home — no gym, no equipment required. It walks you from a quick setup through a personalized daily workout, a 28-day challenge, and long-term progress tracking.

## Getting started

1. Open `index.html` in any modern browser (Chrome, Safari, Edge, Firefox).
2. No install, server, or account needed — it's a single self-contained file.
3. Progress is kept in memory for the current browser session only. Refreshing or closing the page resets your streak, completed workouts, and challenge status, since the app doesn't use any persistent storage.

## What's inside

**Setup**
- Name, age, experience level (Beginner / Intermediate / Advanced)
- Preferred workout duration and days per week
- Available equipment (none, chair, backpack, resistance band, other)
- Voice guide selection (male / female / off) with a Test Voice button

**Dashboard**
- Today's personalized workout with estimated time and difficulty
- Current streak, weekly progress, and total completed workouts
- A "progress wall" that fills in brick by brick as you complete challenge days

**Goals**
- Pick one primary goal (Chest, Arms, Shoulders, Core, Legs, Full Body, Push-Up Progress, or the 28-Day Challenge) plus optional secondary goals
- Your plan is generated from the selected goal and experience level

**28-Day Challenge**
- Four weeks — Foundation, Build, Progress, Challenge
- Each day shows its exercises, sets/reps, and rest periods, with rest days built in
- Tap any day to preview or start it

**Workout Programs**
- Chest Builder, Abs & Core, Lower Body, and Full Body
- Each has Beginner / Intermediate / Advanced levels

**Exercise flow**
- Instruction screen for every exercise: target muscles, how to perform it, common mistakes, a "watch demo" preview, and an easier-version option
- Live workout screen with a rep counter or countdown timer, set tracking, and a rest timer (+15s / +30s / skip)
- Voice coaching narrates set starts, countdowns, rest periods, and transitions (uses your browser's built-in speech synthesis, so available voices vary by device)

**Exercise Library**
- Searchable, filterable by muscle group
- Each entry shows target muscles, instructions, common mistakes, and its progression path (easier → standard → harder variation)

**Progress**
- Streak, total workouts, weekly consistency ring, challenge completion
- Manually loggable personal records (max push-ups, max squats, plank hold time)

**Also included**
- A dedicated rest-day screen with light recovery suggestions
- A general nutrition guide (balanced meals, protein, water, sleep — no extreme diets or supplements)
- Settings for voice, notifications, editing your profile/goal, and resetting progress

## Notes

- This is a self-contained demo build: all data lives in the browser tab's memory, so nothing is saved between sessions or synced across devices.
- The voice coach depends on the speech voices installed on your device/browser — use Test Voice in setup to check what's available before choosing.
- HomeBulk provides general fitness guidance only. Use proper technique, progress gradually, and stop if an exercise causes pain. If you have an injury or medical condition, consult a qualified professional before starting a new exercise program.
